# parcial-2-programacion-3
Entrega Nikoll Morales Londoño. Programación funcional con Elixir | Recursividad, Streams y structs. 
Problemas escogidos: 1 y 2.

Para el problema 1 abrir una terminal en la carpeta problema1 y ejecutar:

elixir main.exs

Para correr las pruebas:

elixir main.exs pruebas/errores
elixir main.exs pruebas/limite
elixir main.exs pruebas/vacio

Los resultados quedan en archivos .txt

y para el problema 2 abrir una terminal en la carpeta problema2 y ejecutar:

elixir main.exs

Para correr las pruebas:

elixir main.exs pruebas/errores
elixir main.exs pruebas/limite
